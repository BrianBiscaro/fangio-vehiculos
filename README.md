# 🚗 Fangio Vehículos - Sistema de Gestión

Plataforma web integral para la automatización de reservas, pagos y gestión administrativa de la escuela de manejo Fangio Vehículos.

## 🛠️ Tecnologías Principales
* **Frontend:** React (Vite)
* **Backend:** Java + Spring Boot
* **Base de Datos:** PostgreSQL
* **Infraestructura:** Docker & Docker Compose
* **Pagos:** Integración con API de MercadoPago

## ⚙️ Estructura del Proyecto (Monorepo)
Este repositorio contiene tanto el código del cliente como el del servidor:
* `/frontend` - Aplicación SPA en React para usuarios y administradores.
* `/backend` - API REST desarrollada en Spring Boot.
* `docker-compose.yml` - Configuración para levantar la base de datos local.
